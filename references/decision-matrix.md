# 目录分级矩阵

判断一个目录能否搬迁，看三个维度：**归属**（用户数据 / 应用数据 / 程序本体 / 系统）、**写入活跃度**、**路径绑定程度**。

下表用"路径模式"描述，而不是某个具体软件的名字——同样类型的目录在任何软件上都适用。

## 可搬（安全级）

| 类别 | 路径模式 | 说明 |
| --- | --- | --- |
| 通用缓存 | `%USERPROFILE%\.cache`、`%LOCALAPPDATA%\<工具名>\Cache`、`%LOCALAPPDATA%\Temp` | 纯可再生数据，搬走或删除都无风险 |
| 包管理器缓存 | npm / pnpm / pip / cargo / go / maven 的 cache、store、registry 目录 | 建议同时用各自的配置命令把缓存路径指向新位置，避免以后又长回来 |
| 编辑器与 IDE 索引 | `%LOCALAPPDATA%\<IDE 厂商>`、`%APPDATA%\<IDE 厂商>`、编辑器扩展目录 | 关闭 IDE 后迁移；索引会在下次打开时自动重建 |
| 命令行工具数据 | `%USERPROFILE%\.<工具名>` 下的缓存、日志、会话目录 | 关闭对应进程后迁移，否则复制期间仍会被写入 |
| 聊天与办公客户端 | `%APPDATA%\<客户端目录>` 里的缓存、接收文件、媒体 | 需完全退出客户端（含托盘与后台进程） |
| 用户可视目录 | `Desktop`、`Downloads`、`Documents`、`Pictures`、`Videos` | 搬迁后原路径仍以联机目录形式出现，资源管理器表现正常 |
| 临时目录 | `%TEMP%`、`%TMP%` | 更推荐直接改环境变量指向其他盘 |
| 日志与崩溃转储 | 各应用的 `logs`、`crashpad`、`CrashDumps`、`dumps` | 可直接删除或迁移 |
| 安装器与更新器下载 | `*-updater`、`*-installer`、`Pending` 目录 | 通常可整目录删除，不必迁移 |

## 谨慎（条件级）

| 类别 | 处理方式 |
| --- | --- |
| 运行中的应用数据（AI 助手、协作工具、笔记软件） | 迁移会中断写入，复制期间字节数必然变化。先完全退出应用；做不到就保留不搬 |
| 浏览器配置（用户数据目录） | 需退出浏览器。迁移后书签、扩展、登录态一般保留，但个别应用绑定设备标识，建议先备份 |
| 容器运行时数据与镜像 | 优先在应用设置里改镜像/数据位置；用联接可能因服务启动顺序出现权限问题 |
| SDK 与语言运行时（Python 发行版、版本管理器目录） | 可搬，但 PATH、IDE 解释器配置里的绝对路径需同步检查 |
| 虚拟机磁盘、网盘同步目录、游戏安装目录 | 用应用自身设置改路径，不要用联接 |
| 数据库文件（`.db`、`.sqlite`、`.mdf`、`.ibd`） | 迁移前停止服务；部分数据库引擎不认联接，须用其自身文件路径设置 |
| 签名、证书、密钥目录 | 一般不搬；若必须搬，迁移后验证签名与加密功能 |

## 禁止（不可搬）

| 目录 | 原因 |
| --- | --- |
| `Windows`、`WinSxS`、`System32` | 系统组件，只能用 DISM 清理，不能搬 |
| `Program Files`、`Program Files (x86)` | 安装器、卸载器、服务注册、COM 注册均绑定绝对路径；搬走会导致卸载失败、更新失败、开机启动异常 |
| `%LOCALAPPDATA%\Programs\*`（应用本体） | 同上，属程序本体而非数据 |
| 驱动目录、`ProgramData` 下的服务数据 | 系统服务以 SYSTEM 身份按原路径加载 |
| 用户配置单元（`NTUSER.DAT`、`UsrClass.dat`） | 登录时加载，移动会导致无法登录 |
| 加密目录（EFS / BitLocker 容器） | 联接会破坏加密边界 |

## 参考量级

一次典型的执行通常能拿到这些量级，实际取决于机器内容：

| 动作 | 参考释放 |
| --- | --- |
| 清空系统盘回收站 | 5–20GB（与删除习惯强相关） |
| 迁移缓存、IDE 数据、聊天接收文件 | 5–15GB |
| 迁移桌面与下载目录 | 1–10GB |
| DISM 压缩 WinSxS | 3–5GB |
| 关闭保留存储 | 约 7GB |
| 页面文件移到其他盘 | 等于原页面文件大小（常见 8–16GB） |
| 关闭休眠 | 约等于内存容量 |

单项都不大，叠加起来通常能释放 20–40GB。判断能不能做，不看目录名，而看它是否满足：不在程序安装目录内、当前没有进程在写、路径没有被注册表或服务写死。
